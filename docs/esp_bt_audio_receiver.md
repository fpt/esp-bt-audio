# ESP32 Bluetoothオーディオレシーバー 設計書

## 1. 概要

iPhoneからBluetooth Classic（A2DP）で音声を受信し、ヘッドホンで再生するバッテリー駆動のレシーバー。タクトスイッチによる操作と RGB LED による状態表示に対応する。

基板は 2 枚構成。

| 基板 | 内容 |
|---|---|
| main（`main/`） | ESP32-WROOM-32E、ボタン、LED、電源ラッチ、電池電圧分圧、書き込みヘッダ |
| i2s-power（`i2s/`） | TP4056 モジュール、RT9080（3.3V）、PT8211、LM4881、ヘッドホンジャック |

2 枚は 12 ピンのヘッダでつながる（3V3 / GND / BCLK / WS / DIN / MUTE / 3V3_EN / VDD など）。

### 要求仕様

| 項目 | 内容 |
|---|---|
| 接続 | Bluetooth Classic A2DP Sink（コーデックはSBC）／AVRCPで再生操作 |
| 対応機器 | iPhone |
| 出力 | ヘッドホン（ステレオ） |
| 電源 | 1セルLiPo、USB充電 |
| 連続再生 | 5時間以上 |
| 表示 | WS2812B-V6 RGB LED ×1 |
| 操作 | 電源ボタン（タクトスイッチ）×1、BT ボタン（タクトスイッチ）×1 |
| 書き込み | 6ピン ジグザグヘッダ（GND / G0 / EN / RX / TX / 3V3）＋ M5Stack ESP32-Downloader |

## 2. ブロック図

```
              USB 5V
                │
        ┌───────▼────────┐
LiPo ───┤ TP4056(保護付) ├── OUT+ (VDD = VBAT) ──┬──► 電源SW / 電池電圧分圧（main 基板）
        └────────────────┘                       ▼
                                          RT9080-33 (LDO) ◄── 3V3_EN: 電源SW / GPIO15 (自己保持)
                                                 │ 3.3V
                 ┌─────────────┬─────────────────┼──────────────┐
                 ▼             ▼                 ▼              ▼
           ESP32-WROOM-32E   PT8211           LM4881       WS2812B-V6
                 │
     I2S ────────┴──► PT8211 ──(AC結合)──► LM4881 ──(出力C)──► ヘッドホン
     GPIO ──────────► WS2812B / LM4881 SHUTDOWN
     GPIO ◄───────── ボタン / 電池電圧
     UART0/EN/IO0 ─► 書き込みヘッダ
```

3.3V 系はすべて RT9080 の出力なので、電源 OFF 時に電池から流れるのは電池電圧分圧（約 21µA）と RT9080 のシャットダウン電流だけになる。

## 3. 電源回路

### 3.1 構成

| 区間 | 部品 | 備考 |
|---|---|---|
| 充電・保護 | TP4056モジュール（保護付き） | B+/B− に電池、IN−/OUT− を GND、OUT+ を VDD へ。B− は GND に接続しない |
| 電源スイッチ | タクトスイッチ ＋ 1N4148 ×2 | ソフトラッチ（3.4 参照） |
| 3.3V生成 | RT9080-33 | EN（3V3_EN）は電源スイッチと GPIO15 で制御、100kΩ でプルダウン |
| アンプ電源 | LM4881 | 3.3V。LDO と一緒に OFF になる |

### 3.2 RT9080 周辺

- VIN：1µF 以上（10µF 推奨）
- VOUT：1µF ＋ ESP32 の電源ピン近くに 10〜22µF（無線送信時の電流変動とブラウンアウト対策）
- 各ICの電源ピン直近に 0.1µF を配置する
- 電池電圧が約3.2Vになるまで ESP32 の動作電圧（3.0V以上）を維持できる

### 3.3 電池電圧モニタ

```
VDD ──[100kΩ]──┬──[100kΩ]── GND
               ├── GPIO35 (ADC1_CH7)
               └──[0.1µF]── GND
```

- 分圧比は 1/2 で、4.2V のとき 2.1V になる
- ADC1 を使うため Bluetooth 動作中でも読める
- 常時 21µA ほど流れるが、影響は無視できる

### 3.4 電源スイッチ（ソフトラッチ）

```
VDD ──[SW_PWR]──┬──[D3 1N4148]──┬── 3V3_EN (RT9080 EN)
                │               ├──[100kΩ]── GND   (i2s-power 基板)
                │   GPIO15 ──[D1 1N4148]┘
                │
                ├──[22kΩ]──┬── GPIO34 (PWR_BTN)
                │          │
                └──────────┴──[100kΩ]── GND
```

- SW_PWR を押すと 3V3_EN が High になり、RT9080 が起動する
- ESP32 は起動後すぐに GPIO15 を High にして EN を保持する
- SW_PWR の状態は GPIO34 で読む。押している間は 2.7〜3.4V（電池 3.3〜4.2V）になる
- 電源 OFF は、ファームウェアが GPIO15 を Low にして行う。SW_PWR を離した時点で電源が落ちる
- D1 は、スイッチを押している間に VDD（〜4.2V）が GPIO15 に回り込むのを防ぐ
- D3 は、GPIO15 が保持している電圧（約 2.6V）が GPIO34 側に回り込むのを防ぐ

## 4. ピンアサイン（ESP32-WROOM-32E）

| 機能 | 信号 | GPIO | 備考 |
|---|---|---|---|
| I2S | BCK | 26 | PT8211 BCK |
| I2S | WS | 25 | PT8211 WS |
| I2S | DATA | 27 | PT8211 DIN |
| アンプ | SHUTDOWN | 23 | LM4881 SHUTDOWN（High でシャットダウン） |
| ボタン | BTN_A1 | 13 | BT ボタン。押すとLow（内部プルアップを使用） |
| ボタン | PWR_BTN | 34 | 電源ボタンの状態。押すとHigh（分圧入力） |
| LED | RGB_LED | 14 | WS2812B-V6 DIN（220Ω 直列） |
| 電源保持 | PWR_EN | 15 | 1N4148 経由で 3V3_EN |
| 電池電圧 | BAT_SENSE | 35 | 入力専用ピン、分圧入力 |
| 書き込み | U0TXD | 1 (TX) | ヘッダ |
| 書き込み | U0RXD | 3 (RX) | ヘッダ |
| 書き込み | BOOT | 0 | ヘッダ、内部プルアップ |
| 書き込み | EN | EN | ヘッダ、10kΩプルアップ＋1µF |

### 避けたピン

| ピン | 理由 |
|---|---|
| GPIO6〜11 | 内蔵フラッシュに接続されている |
| GPIO0, 2, 5, 12 | ストラッピングピン。特に GPIO12 は起動時に High だとフラッシュ電圧が変わり起動しなくなる |
| GPIO34〜39 | 入力専用で内部プルアップがない（電池電圧と電源ボタンの読み取りには問題ない） |

GPIO15 もストラッピングピンだが、起動時のレベルは起動ログの出力に影響するだけなので、電源保持に使っている。

## 5. オーディオ回路

### 5.1 PT8211（I2S DAC）

- 電源は 3.3V。5V で動かすと ESP32 の 3.3V ロジックを High と認識しない恐れがある
- フォーマットは LSB Justified 16bit。16bit スロットなら MSB Justified と同じ波形になるので、ファームウェアは MSB 形式で出力している
- 電源ピンに 0.1µF ＋ 10µF を配置する
- 出力 L/R は 1µF のコンデンサでカップリングして LM4881 へ入力する
- デジタルフィルタを持たないので、LM4881 の Rf に 220pF を並列に入れてローパスにしている（fc ≈ 36kHz）

### 5.2 LM4881（ヘッドホンアンプ）

反転増幅構成で、ゲインは −Rf/Ri。

| 部品 | 定数（目安） | 備考 |
|---|---|---|
| Ci（入力カップリング） | 1µF | PT8211 出力の直流成分をカット |
| Ri | 20kΩ | |
| Rf | 20kΩ | ゲイン1倍。音量が足りなければ Rf を大きくする |
| Cf（Rf に並列） | 220pF | ローパス。fc ≈ 36kHz |
| CB（バイパス） | 1µF | 起動時のポップ音にも影響する |
| Co（出力カップリング） | 470µF | 32Ω 負荷で fc ≈ 11Hz |
| 電源パスコン | 0.1µF ＋ 10µF | |

- SHUTDOWN 端子は GPIO23 で制御する。i2s-power 基板側で 100kΩ により 3.3V にプルアップされているので、起動時はシャットダウン状態で始まる
  - High でシャットダウンする。電源も 3.3V なので、ESP32 の High 出力で確実にシャットダウンできる
- ファームウェアは再生開始でアンプを ON にし、停止から 5 秒後に OFF にする
- 定数は LM4881 データシートの代表回路を基に最終確認する

## 6. 操作・表示部

### 6.1 ボタン

| ボタン | 操作 | 動作 |
|---|---|---|
| 電源（SW5） | 押す | 電源 ON（LED が点くまで押し続ける） |
| 電源（SW5） | 2 秒長押し | 電源 OFF（LED が赤になり、離すと電源が落ちる） |
| BT（SW6） | 押す | 再生／一時停止 |
| BT（SW6） | 3 秒長押し | ペアリングモード（接続中のスマホを切断して検出可能にする） |

- BT ボタンは「GPIO ── スイッチ ── GND」の配線で、ESP32 の内部プルアップを使う
- チャタリングにはソフトで対処する（20ms ごとに読み、60ms 安定で確定）

### 6.2 RGB LED（WS2812B-V6）

- 3.3V で動作する品種なので、RT9080 の出力から給電する。電源 OFF 時は消費電流ゼロ
- データ線は GPIO14 から 220Ω を直列に入れる
- 表示は [firmware/README.md](../firmware/README.md) を参照（青点滅: ペアリング、青: 接続、緑: 再生中、赤点滅: 電池低下）

## 7. 書き込み

### 7.1 本体側ヘッダ（6ピン、ジグザグ配置）

```
 1: GND
 2: G0    (ESP32 GPIO0)
 3: EN
 4: TX    (Downloader TX → ESP32 U0RXD / GPIO3)
 5: RX    (Downloader RX ← ESP32 U0TXD / GPIO1)
 6: 3V3   (3.3Vレール = RT9080 出力に直結)
```

ピン穴を互い違いにずらしてあるので、ピンヘッダを差し込むだけで接触が保たれ、はんだ付けなしで M5Stack ESP32-Downloader を接続できる。

周辺回路：

```
3.3V ──[10kΩ]──┬── EN
               └──[1µF]── GND
```

- WROOM-32E は EN を内部でプルアップしていないので、本体側に 10kΩ と 1µF を付けている。Downloader を外しても EN は浮かない
- GPIO0 は内部プルアップがあるので外付け抵抗は不要

**3V3 ピンから外部給電するときは、本体の電源を OFF にする。** RT9080 の出力と外部の 3.3V がぶつかるのを防ぐため。

- 電源 OFF の状態でも、RT9080 を逆流して VIN 側（LM4881 の電源）にわずかに電圧が回り込む可能性がある
- LM4881 は 2.7V 以上で動作する部品なので害はないが、気になる場合は RT9080 の逆流特性をデータシートで確認する

### 7.2 書き込み手順

1. 本体の電源を OFF にする
2. M5Stack ESP32-Downloader を本体ヘッダに差し込み、USB を PC につなぐ
3. `firmware/` で `make flash PORT=COMx` を実行する。Downloader の自動リセット回路でダウンロードモードに入る

ジャンパ線が長くて書き込みエラーが出る場合は、Upload Speed を 460800 か 115200 に下げる。

## 8. 消費電流と電池容量

| 部品 | 消費電流（目安） |
|---|---|
| ESP32（A2DP 受信中、WiFi オフ） | 100〜130mA |
| PT8211 | 数mA |
| LM4881 ＋ ヘッドホン | 5〜15mA |
| WS2812B-V6 | 1mA（消灯時）〜十数mA（点灯時） |
| プルアップ・分圧など | 1mA 未満 |
| **合計** | **約110〜160mA** |

- 5時間再生に必要な容量は 160mA × 5h ≒ 800mAh
- 余裕を見て **1200〜1500mAh の LiPo** を推奨する
- LED を必要なときだけ点灯すれば、さらに長持ちする

ESP-IDF v5.4 のファームウェアを `firmware/` に置いている。ビルド・書き込み・動作は [firmware/README.md](../firmware/README.md) を参照。

### 9.1 構成

| 用途 | 実装 |
|---|---|

| I2S 出力 | `driver/i2s_std.h`、MSB justified 16bit（16bit スロットなら PT8211 の LSB justified と同じ波形） |
| 音量 | AVRCP 絶対音量でサンプルをスケーリング |
| LED | RMT で WS2812B を駆動 |
| 電池電圧 | ADC1 oneshot ＋ キャリブレーション |

### 9.2 省電力

- WiFi は使わない
- CPU クロックは 160MHz
- アンプは再生中だけ動作させ、停止 5 秒後にシャットダウンする
- 電池が 3.2V を下回るか、10 分間接続がなければ自動で電源を切る

## 11. 実装上の注意

- **アンテナ周辺を空ける。** WROOM のアンテナ部の下と周囲には銅箔や GND を置かない
- **アナログ部を離す。** PT8211 と LM4881 はアンテナや LDO から離して配置する
- **GND 配線。** GND は太く短く配線する。可能ならアナログ GND を1点でデジタル GND に接続する
- **ノイズが出たら。** 「ジー」というノイズが出る場合は、LM4881 の電源パスコンを強化し、PT8211 の 3.3V に RC フィルタ（10Ω ＋ 47µF）を入れてみる
