# I2S オーディオ出力回路 設計メモ
PT8211 (LSBJ DAC) → LM4881 (ヘッドホン, ステレオ) ＋ PAM8302 (スピーカー, モノラル)

## 1. 概要

- 入力: マイコンの I2S（LSB justified / 右詰め, 16bit）
- DAC: PT8211（秋月）
- ヘッドホン: LM4881MX（ステレオ、32Ω直結可）
- スピーカー: PAM8302A モジュール（モノラル D級、BTL 出力）
- 切替: スイッチ付き 3.5mm ジャック。プラグ挿入で PAM8302 の /SD を Low にしてスピーカーを停止
- 電源: 3.3V 単一（5V でも可。5V にする場合は PT8211 だけ 3.3V で動かす）

### ブロック図

```
                 ┌─ RC LPF ─ C ─ LM4881 A ─┬─ 220µF ─ (R) ─ ジャック Tip
PT8211 L ────────┘                         │
                                           └─ 10kΩ ─┐
                                                    ├─ VR ─ 1µF ─ PAM8302 IN+ ─→ SP
                                           ┌─ 10kΩ ─┘           IN- ─ 1µF ─ GND
PT8211 R ────────┐                         │
                 └─ RC LPF ─ C ─ LM4881 B ─┴─ 220µF ─ (R) ─ ジャック Ring

ジャック スイッチ接点 ──→ PAM8302 /SD  （未挿入: High=動作 / 挿入: Low=停止）
```

- LM4881 は常時動作し、ヘッドホン経路とスピーカー用ミックスの両方を駆動する
- L+R ミックスは LM4881 出力（低インピーダンス）から取るので、クロストークは実用上無視できる
- LM4881 は反転アンプだが、L/R 両方反転するためヘッドホンでは問題なし。モノラルスピーカーも単独なので無関係

## 2. 電源

| ブロック | 電圧 | 備考 |
|---|---|---|
| PT8211 | 3.3V | 2.0〜5.5V 動作。5V だと VIH=3.5V になり 3.3V ロジックが規格割れするので 3.3V で動かす |
| LM4881 | 3.3V（〜5.5V） | 3.3V 時 32Ω で 50〜70mW 程度 |
| PAM8302 | 3.3V（〜5.5V） | 3.3V 時 4Ω で約 1W。5V なら 2.5W |

- 各 IC の電源ピン直近に 0.1µF、PAM8302 には加えて 10µF 以上
- GND は一点集合（PT8211 / LM4881 / ジャック / PAM8302）。PAM8302 のスピーカー電流がヘッドホン GND 経路に流れないように配線する

## 3. PT8211 まわり

- 出力には VDD/2 の DC オフセットが乗る → 必ずコンデンサでカップリング
- 出力の後に簡単な RC ローパス: **1kΩ ＋ 4.7nF**（fc ≈ 34kHz）
- 負荷は 10kΩ 以上にする（LM4881 の Ri=20kΩ で OK）
- 出力レベルは 3.3V 動作で数百 mVrms 程度（フルスケール時）

### I2S 設定（マイコン側）

- PT8211 は LSB justified（右詰め）16bit
- **スロット幅 16bit・データ 16bit なら、左詰め（MSB justified）と波形が同一** になるので、MSB justified 16bit で設定すればよい
  - ESP-IDF `i2s_std`: `I2S_STD_MSB_SLOT_DEFAULT_CONFIG(I2S_DATA_BIT_WIDTH_16BIT, I2S_SLOT_MODE_STEREO)`
  - ESP8266Audio: `AudioOutputI2S::SetLsbJustified(true)`
  - RP2040: PIO で自前実装
- Philips 形式（1bit 遅れ）に設定すると音量半分＆歪むので注意
- 接続: BCK, WS(LRCK), DIN の 3 本。MCLK 不要

## 4. LM4881（ヘッドホンアンプ）

反転アンプ構成。ゲイン = Rf / Ri。

| 部品 | 値 | 役割 |
|---|---|---|
| Ci（入力カップリング） | 1µF | fc = 1/(2π·20k·1µ) ≈ 8Hz |
| Ri | 20kΩ | 入力抵抗 |
| Rf | 20kΩ | 帰還抵抗（ゲイン 1 倍）。音量を抑えたければ 10kΩ（0.5 倍） |
| Cb（BYPASS） | 1µF | 内部 VDD/2 バイアスの平滑。ポップ低減のため 1µF 以上 |
| Co（出力カップリング） | 220µF | fc = 1/(2π·32·220µ) ≈ 23Hz。+ 側が IC 出力 |
| Ro（出力直列） | 0〜22Ω | 保護用。32Ω 直結可なので省略可 |
| Cs（電源） | 0.1µF ＋ 10µF | VDD 近くに配置 |

- SHUTDOWN ピンは使わないなら動作側の電位に固定する（極性はデータシートで要確認）
- MSOP パッケージなので変換基板を使う
- ヘッドホン用ボリュームを付ける場合は Ci の前に 10kΩ 2 連ポット（この場合スピーカー音量も連動する）

## 5. モノラルミックスと PAM8302

```
LM4881 OUT A ─ 10kΩ ─┐
                     ├─(加算点)─ 10kΩ 半固定 ─ 1µF ─ PAM8302 IN+
LM4881 OUT B ─ 10kΩ ─┘                        PAM8302 IN- ─ 1µF ─ GND
```

- ミックスは **出力カップリング 220µF の前**（IC 出力直後）から取る。後ろから取るとヘッドホン挿抜でポップが出やすい
- 加算点には VDD/2 の DC が乗るが、PAM8302 手前の 1µF で切れる
- PAM8302 はゲイン 24dB 固定、入力 0.5Vrms 程度でフルスイング。L+R で振幅が増えるので、半固定抵抗（または固定分圧）でレベルを合わせる
- IN- は 1µF で GND へ（シングルエンド入力として使用）
- スピーカーは BTL 出力 OUT+/OUT- に接続。**スピーカーの − 端子を GND に落とさない**
- シャットダウン中の PAM8302 入力は高インピーダンスなので、ヘッドホン側に影響しない

## 6. ジャックと /SD 制御

スイッチ付き 3.5mm ジャック（例: MJ-355 系）は、プラグ未挿入時に Tip / Ring がスイッチ端子と導通している。

```
VDD ─── ジャック スイッチ接点 ───┬─── PAM8302 /SD
                                │
                              100kΩ
                                │
                               GND
```

- 未挿入: 接点閉 → /SD = High → スピーカー動作
- 挿入: 接点開 → /SD = Low → スピーカー停止
- Adafruit 版 PAM8302 モジュールは基板上に 100kΩ プルアップがある。上記のプルダウン 100kΩ と分圧になるため、未挿入時は接点経由で VDD に直結されるので問題ないが、気になればモジュール側のプルアップを外すか、プルダウンを 47kΩ にする
- 接点には信号電流しか流れないので、安価なジャックでも問題ない
- PAM8302 はポップ抑制機能があるので、切替時のノイズは小さい

## 8. 動作確認の順番

1. PT8211 単体: I2S 設定後、出力を直接オシロで確認（DC オフセット ＋ 波形）。音量が半分/歪む場合は LSBJ 設定を疑う
2. LM4881: ヘッドホンで L/R が正しく、かつ分離していることを確認
3. PAM8302: /SD を手動で High にしてスピーカーが鳴ること、半固定でレベル調整
4. ジャック挿抜で切替とポップ音を確認
