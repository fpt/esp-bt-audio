# I2S オーディオ出力回路 設計メモ
PT8211 (LSBJ DAC) → LM4881 (ヘッドホン, ステレオ)

## 1. 概要

- 入力: マイコンの I2S（LSB justified / 右詰め, 16bit）
- DAC: PT8211（SOP-8）
- ヘッドホン: LM4881MX（SOIC-8、ステレオ、32Ω直結可）
- 電源: 2 系統。PT8211 は 3V3、LM4881 は VDD（3.3〜5.5V。本体では VBAT 3.0〜4.2V）

### ブロック図

```
PT8211 L ─ 1µF ─ LM4881 B (Rf ∥ 200pF) ─ 470µF ─ ジャック Tip
PT8211 R ─ 1µF ─ LM4881 A (Rf ∥ 200pF) ─ 470µF ─ ジャック Ring
```

- LM4881 は反転アンプだが、L/R 両方反転するためヘッドホンでは問題なし

### 接続ヘッダ

| ピン | 信号 | 備考 |
|---|---|---|
| 1 | 3V3 | PT8211 電源 |
| 2 | GND | |
| 3 | BCLK | |
| 4 | WS | |
| 5 | DIN | |
| 6 | SHUTDOWN | LM4881 SHUTDOWN。High でシャットダウン |
| 7〜9 | NC | |
| 10 | VDD | LM4881 電源 |

## 2. 電源

| ブロック | 電圧 | 備考 |
|---|---|---|
| PT8211 | 3V3 | 2.0〜5.5V 動作。5V だと VIH=3.5V になり 3.3V ロジックが規格割れするので 3.3V で動かす |
| LM4881 | VDD（3.3〜5.5V） | 3.3V 時 32Ω で 50〜70mW 程度 |

- 各 IC の電源ピン直近に 0.1µF ＋ 10µF
- GND は一点集合（PT8211 / LM4881 / ジャック）

## 3. PT8211 まわり

- 出力には VDD/2 の DC オフセットが乗る → 必ずコンデンサでカップリング
- PT8211 はデジタルフィルタを持たないので、高域のイメージ成分を落とす。LM4881 の帰還抵抗 Rf に 200pF を並列に入れてローパスにしている（fc = 1/(2π·20k·200p) ≈ 40kHz）
- 負荷は 10kΩ 以上にする（LM4881 の Ri=20kΩ で OK）
- 出力レベルは 3.3V 動作で数百 mVrms 程度（フルスケール時）

### I2S 設定（マイコン側）

- PT8211 は LSB justified（右詰め）16bit
- **スロット幅 16bit・データ 16bit なら、左詰め（MSB justified）と波形が同一** になるので、MSB justified 16bit で設定すればよい
  - ESP-IDF `i2s_std`: `I2S_STD_MSB_SLOT_DEFAULT_CONFIG(I2S_DATA_BIT_WIDTH_16BIT, I2S_SLOT_MODE_STEREO)`
  - ESP8266Audio: `AudioOutputI2S::SetLsbJustified(true)`
  - RP2040: PIO で自前実装
- Philips 形式（1bit 遅れ）に設定すると音量半分＆歪むので注意
- 接続: BCK, WS(LRCK), DIN の 3 本。MCLK 不要

## 4. LM4881（ヘッドホンアンプ）

反転アンプ構成。ゲイン = Rf / Ri。

| 部品 | 値 | 役割 |
|---|---|---|
| Ci（入力カップリング） | 1µF | fc = 1/(2π·20k·1µ) ≈ 8Hz |
| Ri | 20kΩ | 入力抵抗 |
| Rf | 20kΩ | 帰還抵抗（ゲイン 1 倍）。音量を抑えたければ 10kΩ（0.5 倍） |
| Cf（Rf に並列） | 200pF | ローパス。fc ≈ 40kHz |
| Cb（BYPASS） | 1µF | 内部 VDD/2 バイアスの平滑。ポップ低減のため 1µF 以上 |
| Co（出力カップリング） | 470µF | fc = 1/(2π·32·470µ) ≈ 11Hz。+ 側が IC 出力。耐圧 6.3V 以上 |
| Cs（電源） | 0.1µF ＋ 10µF | VDD 近くに配置 |

- SHUTDOWN ピンは 100kΩ で VDD にプルアップしている。起動時はシャットダウン状態で始まり、マイコンが Low に駆動すると動作する
  - VDD が 5V でマイコンが 3.3V の場合、High 出力（3.3V）で確実にシャットダウンできるかはデータシートの閾値で確認する。オープンドレイン出力にすればプルアップで VDD まで上がる
- ヘッドホン用ボリュームを付ける場合は Ci の前に 10kΩ 2 連ポット

## 6. 動作確認の順番

1. PT8211 単体: I2S 設定後、出力を直接オシロで確認（DC オフセット ＋ 波形）。音量が半分/歪む場合は LSBJ 設定を疑う
2. LM4881: SHUTDOWN を Low にして、ヘッドホンで L/R が正しく、かつ分離していることを確認
3. ジャック挿抜でポップ音を確認
