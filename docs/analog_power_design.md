# アナログ電源の分離 設計メモ（v0.3.0）

v0.2.0 で出た Bluetooth 連動のノイズへの対策として、PT8211 / LM4881 の電源を 3V3 から分離する。
`v0.3.0_plan.md` の「4.1 アナログ電源の分離」の案 2 を具体化したもの。

## 1. 背景

- Bluetooth 動作中、ヘッドホンから「ジー」というノイズ（約 100Hz ＋ 高調波）が出る。無線の通信頻度に連動する
- i2s-power 基板の 3V3 は 1 本のレールで、ESP32（無線動作時にパルス状に 100〜300mA）と PT8211 / LM4881 が共用している
- PT8211 は抵抗ラダー型 DAC で、電源除去比がほぼない。出力は VDD 基準（無信号で VDD/2）なので、3V3 のリップルがほぼ半分の振幅で出力に出る

## 2. v0.2.0 での検証

### 2.1 経路の切り分け（パターンを切る前に行う）

Ci（1µF ×2）の PT8211 側を外し、Ci の入力側をアナログ GND（LM4881 の GND 付近）に落として Bluetooth を接続する。

| 結果 | 判断 |
|---|---|
| ノイズが消える | PT8211 の電源経由。電源の分離が効く |
| ノイズが残る | LM4881 の電源か GND の経路。GND の配線（検証 B）と LM4881 の電源（検証 C）を先に見る |

### 2.2 PT8211 電源の RC フィルタ（検証 A）

ノイズの基本波が約 100Hz なので、1 次 RC（−20dB/dec）ではカットオフを十分下げる必要がある。

| R | C | fc | 100Hz | 200Hz |
|---|---|---|---|---|
| 22Ω | 100µF | 72Hz | 約 −4dB | 約 −9dB |
| 33Ω | 220µF | 22Hz | 約 −13dB | 約 −19dB |
| 47Ω | 470µF | 7.2Hz | 約 −23dB | 約 −29dB |

- 47Ω ＋ 470µF（低 ESR）＋ 0.1µF から試す
- 入れた後に PT8211 の 5 番ピンの電圧を実測する（3.1V 前後が目安）
- VDD が 3.3V より少し下がるので、I2S の High が VDD をわずかに上回る。0.1〜0.2V なら問題になりにくい
- 1 次 RC で減りきらなければ、電源の分離（3 章）で対策する

### 2.3 NJM2845DL1-33 を使った空中配線での確認（任意）

手持ちの NJM2845DL1-33（3.3V、EN なし）で PT8211 だけを VBAT から給電し、満充電に近い状態でノイズがどこまで消えるかを見る。
「LDO で電源を分ければ十分か、GND 側も直す必要があるか」を発注前に判断するためのもの。
EN がないので本番の構成には使わない。

## 3. 電源の構成

### 3.1 検討した案

| 案 | 内容 | 評価 |
|---|---|---|
| 現状 | 3V3 を ESP32 と共用 | 無線のパルス電流がそのまま PT8211 の出力に出る |
| VBAT 直結 | PT8211 / LM4881 を VBAT から給電 | 電池の内部抵抗と TP4056 モジュールの保護 MOSFET（合計 0.2〜0.3Ω）で、VBAT にも数十 mV のリップルが乗る。PT8211 の出力振幅が電池電圧で 2〜3dB 変わる。電源 OFF にロードスイッチが要る |
| LDO 3.3V（NJM2845DL1-33） | VBAT から 3.3V | EN がないのでロードスイッチが要る。入出力差が 0.3〜0.6V しかなく、無線で VBAT が沈むとリップル除去比が落ちる。電池 3.4V 以下ではほぼ素通し |
| 昇降圧で 5V | DC-DC で 5V を作って給電 | PT8211 の VIH が 3.5V になり、3.3V ロジックが規格割れする。スイッチングのリップル（軽負荷では可聴帯域の断続動作）が乗るので、結局 LDO が要る |
| **LDO 3.0V（NJM2884U1-03）** | VBAT から 3.0V、EN = 3V3_EN | **採用** |

### 3.2 採用構成

```
VBAT ─┬─ RT9080-33 ──────────► ESP32 / LED          EN = 3V3_EN
      └─ NJM2884U1-03 (3.0V) ─┬─► PT8211            EN = 3V3_EN
                              └─► LM4881
```

3.0V にする理由:

- ドロップアウトの余裕。データシートのリップル除去比 75dB は「入力 = 出力 ＋1V」（3.0V 品なら 4.0V）の条件。LiPo が長くいる 3.6〜3.9V で 0.6〜0.9V の余裕があり、ほぼ仕様どおりの条件で使える。自動電源オフ（3.2V）でも 0.2V 残る
- I2S の電圧。ESP32 の 3.3V が PT8211 の VDD を超える分が 0.3V で済む。PT8211 の VIH は約 0.7 × VDD = 2.1V なので、3.3V で十分 High になる

### 3.3 NJM2884U1-03

| 項目 | 値 | 備考 |
|---|---|---|
| 出力 | 3.0V ±1%、500mA | LM4881 も載せられる |
| リップル除去比 | 75dB typ.（1kHz、VIN = 4.0V、Io = 10mA） | 100Hz の値はデータシートのグラフで確認する |
| 出力雑音 | 45µVrms typ. | ノイズバイパスコンデンサ内蔵 |
| ドロップアウト | 0.18V typ.（300mA） | PT8211 の数 mA ではほぼゼロ |
| 無効電流 | 200µA typ.、OFF 時 100nA | |
| CONTROL | ON ≥ 1.6V、OFF ≤ 0.6V、数〜十数 µA | 3V3_EN（約 2.6V、OFF 時は 100kΩ で 0V）を直結できる |
| 外付け | CIN 0.33µF 以上、CO 2.2µF 以上（セラミック可） | |
| パッケージ | SOT-89-5 | 1 CONTROL、2 GND、3 NC、4 VOUT、5 VIN |

- RT9080 と同じ 3V3_EN で一緒に ON / OFF するので、ロードスイッチは要らない
- 出力レベルは 3.3V 動作より約 0.8dB 下がる（聴感上は問題ない）
- LM4881 は 2.7V 以上で動作する。3.0V では出力の振幅が少し減る。音量に余裕が欲しければ VBAT 直結（SHUTDOWN を VDD にプルアップ）も可。その場合もシャットダウン電流は小さいのでロードスイッチは要らない

## 4. I2S 入力

i2s-power 基板の再利用性のため、ヘッダの I2S 入力は GPIO 直結のまま使えるようにする。
PT8211 の VDD（3.0V）を入力が超える分の対策は、i2s-power 基板の中で行う。

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| A | BCLK / WS / DIN の PT8211 入力の直前に 220Ω〜1kΩ を直列 | 部品が少ない。PT8211 の電源 OFF 中に信号源が I2S を出しても電流が制限される | 3.3V 系のホスト向け。5V ロジックでは電流が増える |
| B | 74LVC3G34 などのバッファを 3.0V で動かし、PT8211 の前に入れる | 入力は 5.5V 許容、VIH は約 2.0V。3.3V のマイコンも 5V の Arduino も直結できる。PT8211 に入る信号は必ず 0〜3.0V | 部品が 1 つ増える。バッファの VCC に 10Ω ＋ 1µF 程度の RC を入れる |
| （参考） | 何もしない | 超過分は 0.3V で、保護ダイオードにはほとんど電流が流れない | 絶対最大定格（多くは VDD ＋0.3V）ぎりぎり |

- 直列抵抗は、BCLK（44.1kHz × 32 ≈ 1.4MHz）でも入力容量との時定数が数 ns で問題ない
- 手間を最小にするなら A、どのホストでも使えるようにするなら B

## 5. GND と配置

電源をきれいにすると、次に効いてくるのは GND の共通インピーダンス。

- アナログ部（NJM2884 / PT8211 / LM4881 / ジャック / CB）の GND をまとめ、TP4056 モジュールの OUT− 近くの 1 点で合流させる
- ESP32 の電流ループ（LDO → ヘッダ 3V3 → ESP32 → ヘッダ GND → LDO GND）がアナログ部の下を通らない配置にする
- ヘッダの NC ピンを GND に割り当て、I2S の線のそばに GND を置く
- 根本的には、ESP32 用の LDO を main 基板に移し、ヘッダでは VDD を渡す（`v0.3.0_plan.md` の案 3）と、大電流のループが i2s-power 基板を通らなくなる

## 6. 無線の検波対策（保険）

電源と GND をきれいにしても、2.4GHz の電波をヘッドホンケーブルが拾い、アンプで検波されて同じような「ジー」になることがある。
パターンだけ用意し、必要なら実装する。

- ジャックの出力（Tip / Ring）から GND へ 100pF〜1nF
- LM4881 の入力（Ci の手前）に小さなコンデンサ

## 7. 対策として採らなかったもの

- フェライトビーズ・インダクタ: 効くのは MHz 帯以上で、100Hz のハムには効かない。実装できる 10〜100µH ＋ 100µF の LC では共振周波数が数 kHz になり、100Hz ではほとんど減衰しない。ダンピングが足りないと共振付近で持ち上がる。低い周波数は LDO のリップル除去比で落とす
- もう一段欲しければ、LDO の後に小さな RC（10Ω ＋ 100µF 程度）を足す
