# v0.2.0 のまとめ

v0.2.0（JLCPCB Economic PCBA、2026-11-04 発注）の実機確認の結論と、v0.3.0 のオーディオ部を決めるための対照試験の計画。
経緯と個々の切り分けは `v0.3.0_plan.md` を参照。

## 1. 結論

- **デジタル・電源まわりは動作する。** 起動、電源ラッチ、書き込み、Bluetooth ペアリング、A2DP 再生、LED、L/R の向き（ファームウェアで対応）は OK
- **オーディオ部（PT8211 ＋ LM4881）は作り直す。** 次の 2 つの問題があり、どちらも v0.2.0 の回路の上での手直しでは解決しない
  1. Bluetooth 動作中の「ジー」というノイズ（約 100Hz ＋ 高調波）
  2. iPhone の音量を下げたときの歪み
- ソフトウェア（音声データ、I2S の送り方）は原因ではないことを確認した（2.3）
- これ以上 v0.2.0 での回避策は試さない。v0.3.0 は i2s-power 基板のオーディオ部を別の DAC ／ ヘッドホンアンプに置き換える。部品を決める前に、市販の DAC モジュールで対照試験（4 章）を行う

## 2. 確認した事実

### 2.1 ノイズ

| 条件 | 結果 |
|---|---|
| Bluetooth を止める（無線 OFF） | 消える |
| 接続中・再生なし（iPhone の画面が点いている間） | 出る（無線の通信頻度に連動） |
| 送信電力 -6dBm に制限 | 少し減るだけ |
| 給電元（ESP32-Downloader ／ LiPo） | 変わらない |
| LM4881 が ON の間だけ | 聞こえる（OFF では聞こえない） |
| 音量に対する大きさ | iPhone の音量が小さいと、音楽の 10〜20% 程度に聞こえる |

### 2.2 実装ミスの状態ごとのノイズ（`v0.3.0_plan.md` 1.3）

| 状態 | PT8211 の電源 | I2S | ノイズ |
|---|---|---|---|
| はんだボール（1〜3 番ピン未接続） | あり | なし | あり |
| 向きが逆（VDD・GND とも外れる） | なし | なし | なし |
| 修正後 | あり | あり | あり |

### 2.3 v0.2.0 で試した対策と結果

| # | 試したこと | 結果 | わかったこと |
|---|---|---|---|
| A | PT8211 の VDD に RC フィルタ（27Ω ＋ 220µF ＋ 0.1µF、fc ≈ 27Hz） | ほぼ改善なし | PT8211 の VDD のリップルは主経路ではない |
| S1 | I2S に送るデータをすべて 0 にする（`audio_task` で `memset`） | ノイズは同じ大きさで残る | 音声データ・I2S のアンダーラン（アンダーラン時も 0 が出るだけ）は原因ではない |
| S2 | 全サンプルに DC オフセット 4096 を加える（`CONFIG_BTR_DAC_OFFSET`、試験後に削除） | 歪みが少し減るが大差なし | 低音量の歪みは PT8211 の 0 付近（0x0000 ⇔ 0xFFFF）の誤差だけでは説明しきれない |

### 2.4 歪み

- iPhone の音量が小さいと歪み、最大に近いほどましになる。少し下げただけでも歪む
- ファームウェアは AVRCP の音量をデジタルで掛けている（例: gain 976/16384 ≈ -24dB）。アナログのゲインは固定（Rf = Ri = 20kΩ、1 倍）なので、普段はデジタルで大きく絞った状態で聞くことになる
- 小信号で悪化する固定の誤差・ノイズがあると考えられる。PT8211 は非オーバーサンプリングの抵抗ラダー DAC で、小信号の直線性が悪い

## 3. 原因の見立て

- **PT8211 が今回の用途に合わない。** 電源除去比がほぼなく（出力が VDD 基準）、小信号の直線性が悪い。オーディオ部のノイズと歪みの両方がこの DAC の性質と合う
- **LM4881 の構成も弱い。** 単電源で出力に 470µF が要り、BYPASS（VDD/2）経由で電源ノイズが約 2 倍で出る。アナログのゲインを下げる手段がない
- ノイズの入口（PT8211 の GND か、無線そのものの飛び込みか）は v0.2.0 では確定できていない。4 章の対照試験で、DAC を替えれば消えるのか、main 基板・電源側の問題なのかを分ける

## 4. 対照試験の計画（DAC モジュール）

### 4.1 目的

v0.3.0 の基板を発注する前に、次の 2 点を確かめる。

1. DAC を PCM5102A に替えると、ノイズと低音量の歪みが消えるか
2. ノイズが残る場合、その入口は DAC か、LM4881 か、それ以外（main 基板・電源・無線）か

### 4.2 試験する構成

変えるのはオーディオの経路だけ。ESP32、main 基板、i2s-power 基板の電源（RT9080）、I2S の配線元（ヘッダ）は全構成で同じにする。

| 構成 | DAC | アンプ | イヤホンまで | 変えたもの |
|---|---|---|---|---|
| T1（基準） | PT8211 | LM4881 | 今の i2s-power 基板のまま | なし |
| T2 | PCM5102A モジュール | なし | モジュールのライン出力 → イヤホン | DAC とアンプの両方 |
| T3 | PCM5102A モジュール | LM4881 | モジュール出力 → C3 / C5 → LM4881 | DAC だけ |

- T1 と T3 の差は DAC だけ、T2 と T3 の差はアンプだけになる
- T2 のライン出力はイヤホンには弱いが、ノイズと歪みの有無は判断できる

### 4.3 準備

**モジュール**: PCM5102A のモジュール（GY-PCM5102 など）。裏のジャンパを次に合わせる。

| ピン | 設定 | 意味 |
|---|---|---|
| SCK | GND | MCLK なし（BCK から内部 PLL） |
| FMT | L | I2S（Philips）形式 |
| XSMT | H | ミュート解除 |
| FLT | L | 標準の補間フィルタ |
| DEMP | L | ディエンファシスなし |

**配線**: i2s-power 基板のヘッダから取る。

| ヘッダ | モジュール |
|---|---|
| 3V3 | VIN |
| GND | GND |
| BCLK | BCK |
| WS | LCK |
| DIN | DIN |

- モジュールの電源も i2s-power 基板の 3V3 から取る（電源条件を T1 とそろえる。モジュールの LDO はそのまま使う）
- 線は 10cm 以内、GND はより線にして BCLK / WS / DIN と束ねる
- T2・T3 では PT8211 の 1〜3 番ピンを I2S から外さなくてよい（入力どうしの並列）。ただし T3 では PT8211 の出力が LM4881 に入らないよう、C3 / C5 を PT8211 側で浮かせ、その端にモジュールの L / R 出力をつなぐ

**ファームウェア**: DAC は Kconfig の `BTR_DAC` で切り替える（`CONFIG_BTR_DAC_PT8211` ／ `CONFIG_BTR_DAC_I2S`）。UDA1334A のモジュールも `CONFIG_BTR_DAC_I2S` で使える（SF0 / SF1 = L で I2S 形式）。

| | PT8211（T1） | 標準 I2S の DAC（T2、T3） |
|---|---|---|
| 形式 | MSB（LSB 詰めと同じ）、16 ビットスロット | I2S（Philips）、16 ビットスロット（BCK = 32fs）、MCLK なし |
| L/R の順 | R が先 | L が先（標準）。テストトーンで確認する |

それ以外（音量の掛け方、リングバッファ、送信電力の制限 -6dBm、アンダーランのカウント）は全構成で同じビルドにする。

### 4.4 固定する条件

| 項目 | 内容 |
|---|---|
| 送信側 | 同じ iPhone、同じ曲（静かな部分のある曲を 1 曲決める）、同じ再生位置 |
| 無音の試料 | 無音の音声ファイル（A2DP の再生は続くがデータは 0）。ノイズだけを聞くため |
| 音量 | iPhone の音量を 3 段階に固定: 最大、50%、25%。各段階のファームウェアの gain をログで記録する |
| イヤホン | 同じイヤホン |
| 給電 | LiPo（Downloader は外す） |
| 置き方 | 基板と iPhone の距離・向きを固定（例: 50cm）。基板は机の上で同じ位置 |
| ログ | `make monitor` で `10 s:` の行を記録（`underruns`、`dropped`、`gain`） |

### 4.5 手順

各構成（T1 → T2 → T3）で次を行う。

1. ビルドを書き込み、iPhone と接続する
2. 無音のファイルを再生し、ノイズを聞く（iPhone の音量は最大）
3. 曲を最大、50%、25% の音量で再生し、歪みとノイズを聞く
4. 可能なら、イヤホン出力を PC のライン入力で録音し（同じ録音レベル）、無音時の 100Hz と高調波のレベルを比べる
5. 各条件で `10 s:` の行を 2 つ以上記録する

聞き比べは、T1 と T2 / T3 を交互に切り替えて行う（記憶による比較を避ける）。

### 4.6 判定

| 結果 | 判断 | v0.3.0 |
|---|---|---|
| T2・T3 ともノイズも歪みもない | PT8211 が原因 | PCM5102A ＋ LM4881、または PCM5102A ＋ グラウンド基準のヘッドホンアンプ（TPA6132A2 など） |
| T2 はきれい、T3 でノイズ | LM4881 の段でも入る | PCM5102A ＋ グラウンド基準のヘッドホンアンプ。アナログ電源を分ける |
| T2・T3 とも歪みは消えるがノイズが残る | ノイズは DAC 以外（main 基板・電源・無線） | DAC は替えたうえで、電源と GND を見直す（`v0.3.0_plan.md` 4.1 案 3、4.2）。無線の飛び込みは基板どうしの距離を離して確認する |
| T2・T3 でも歪む | DAC 以外の原因（データ・音量処理） | ファームウェアの音量処理とデータを再確認する |

### 4.7 結果

| 構成 | 無音のノイズ | 最大 | 50% | 25% | underruns | メモ |
|---|---|---|---|---|---|---|
| T1 | | | | | | |
| T2 | なし（2026-11-14、UDA1334A のジャック） | 少し歪む（ライン出力でイヤホンを直接駆動） | | | | とてもきれい |
| T3 | あり（2026-11-14、UDA1334A） | | | | | |

- T2 はきれいで T3 でノイズ → **ノイズは LM4881 の段（電源・BYPASS・出力コンデンサとジャックの GND）から入る**。DAC だけ替えても消えない
- v0.3.0 は DAC に加えて、ヘッドホンアンプも替える（4.6 の 2 行目）

## 5. v0.3.0 の候補（4 章の結果で決める）

| 部品 | 候補 | 備考 |
|---|---|---|
| DAC | PCM5102A（PCM5101A、PCM5100A はピン互換） | 3.3V、MCLK・I2C 不要。PCM5102APWR（C107671）は 2026-11-13 時点で LCSC の在庫 0。発注前に JLCPCB の在庫を確認する |
| ヘッドホンアンプ | TPA6132A2 など、グラウンド基準（出力コンデンサ不要）のもの | EN に今の SHUTDOWN（GPIO23）を使う（極性はファームウェアで変える） |
| アナログ電源 | 低ノイズ LDO（DAC のアナログ電源とアンプ用） | `v0.3.0_plan.md` 4.1 案 2 |

- main 基板と ESP32 の GPIO（BCK 26、WS 25、DATA 27、SHUTDOWN 23）は変えない
- DAC とアンプが 1 つになった IC（TLV320DAC3100 など）は I2C が要り、main 基板とヘッダの変更が必要になるので、第一候補にはしない
