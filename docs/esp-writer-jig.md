## 1. USB シリアル基板（AE-CH9102F-TYPEC-BO）の設定と制約

### ピン配置

| コネクタ | ピン | 機能 |
|---|---|---|
| CN2-1 | VIO | IO 電圧の出力（J1 を外せば入力にもできる） |
| CN2-2 | DTR | Data Terminal Ready 出力（負論理） |
| CN2-3 | RTS | Request To Send 出力（負論理） |
| CN2-4 | CTS | 入力。今回は未使用 |
| CN3-1 | +5V | USB バスパワー 5V 出力。ポリヒューズ MF-FSMF035X（保持 350mA、遮断 750mA） |
| CN3-2 | GND | |
| CN3-3 | TxD | CH9102F からの送信出力 → ESP の RXD へ |
| CN3-4 | RxD | CH9102F への受信入力 ← ESP の TXD から |

### J1（IO 電圧ジャンパ）

- 出荷時は 5V。**必ず 3.3 側に移動する**（はんだ作業）。
- 目的は DTR / RTS / TxD / RxD の信号レベルを 3.3V にすること。

### 重要: VIO の 3.3V は ESP の電源に使えない

- J1 を 3.3 側にしたときの VIO は CH9102F 内蔵レギュレータ（V3）の出力。
- データシートの外部負荷容量 ILDO は **最大 10mA**。
- ESP-WROOM-02 / WROOM-32E は Wi-Fi 送信時に 300〜500mA のピークが出るので、
  ここから給電すると確実にブラウンアウトする。
- ESP の 3.3V は CN3 の +5V から外付け LDO で作る（後述）。

### DTR / RTS の駆動能力（VIO=3.3V 時）

- VOH: 5mA 出力で VIO−0.4V 以上
- VOL: 8mA 吸い込みで 0.4V 以下
- DTC114 の内蔵ベース抵抗（10kΩ）なら 1mA 未満なので十分。

## 2. 3.3V 電源

```
CN3 +5V ---+--- IN  LDO 3.3V  OUT ---+---+--- 3V3 (ESP, プルアップ類)
           |                         |   |
         10µF                     100µF 0.1µF
           |                      (〜470µF) |
          GND                       GND   GND (モジュール直近)
```

- LDO 候補: AMS1117-3.3（手軽）、XC6220B331 / NJM2845（1A 級、余裕あり）。
- 出力側はモジュール直近に 100µF 以上の電解 + 0.1µF。WROOM-32E のピークに備えるなら 470µF。
- ポリヒューズは保持 350mA なので、治具で長時間 Wi-Fi を回す用途には向かない。
  書き込みと簡単な動作確認までなら問題なし。

## 3. 自動書き込み回路（DTC114 ×2、NodeMCU 方式）

DTC114E（R1=R2=10kΩ 内蔵）でも DTC114T（R1=10kΩ のみ）でも、外付け抵抗なしで使える。
DTC114 のピン名: IN = ベース、GND = エミッタ、OUT = コレクタ。

```
                 3V3
                  |
                 10k
                  |
 DTR ----[B] Q1 [C]---+---- EN (WROOM-32E) / RST (WROOM-02)
 RTS ----[E]          |
                     1µF
                      |
                     GND

                 3V3
                  |
                 10k
                  |
 RTS ----[B] Q2 [C]---+---- IO0
 DTR ----[E]
```

- Q1: ベース = DTR、エミッタ = RTS、コレクタ = EN/RST
- Q2: ベース = RTS、エミッタ = DTR、コレクタ = IO0

### 動作表（ピン電圧ベース）

| DTR | RTS | EN/RST | IO0 | 状態 |
|---|---|---|---|---|
| H | H | H | H | 通常動作 |
| L | L | H | H | 通常動作（ターミナルが DTR/RTS 両方をアサートした状態） |
| H | L | L | H | リセット中 |
| L | H | H | L | 書き込みモードで起動 |

esptool の操作順:

1. EN=L, IO0=H（リセット） → 100ms 待ち
2. EN=H, IO0=L（書き込みモードで起動） → 50ms 待ち
3. IO0 を離す

### 「少し遅延させる」の正体と定数

手順 2 の「EN を離す」と「IO0 を下げる」は別々の USB 転送になるため、
数百 µs〜数 ms ずれることがある。コンデンサなしだと IO0 が下がる前に EN が上がり、
通常起動してしまう（特に macOS で起きやすい）。

| 場所 | 値 | 理由 |
|---|---|---|
| EN / RST | 10kΩ プルアップ + 1µF to GND | 時定数 10ms。EN が閾値（約 2.5V）を超えるのは離してから約 14ms 後なので、IO0 が確実に先に下がる。Espressif の ESP32 設計ガイドライン推奨値と同じ |
| IO0 | 10kΩ プルアップのみ | コンデンサを付けると IO0 の立ち下がりが遅れて逆効果 |

- 0.1µF だと時定数 1ms で失敗することがある。1µF 推奨。
- 1µF を DTC114 で放電するときの電流は内蔵ベース抵抗で 20〜30mA 程度に制限されるため、
  定格 100mA に対して問題なし。

### 手動フォールバック

EN-GND と IO0-GND にタクトスイッチを並列に付けておく。
自動リセットが失敗したときは IO0 を押しながら EN を押して離す。

## 4. 治具の共通信号とモジュール別配線

治具側は次の 6 本を共通にし、モジュールごとの DIP 化基板で受ける。

```
3V3 / GND / TxD(→ESP RXD) / RxD(←ESP TXD) / EN-RST / IO0
```

TxD と RxD はクロス接続（CH9102F TxD → ESP RXD、ESP TXD → CH9102F RxD）。

### ESP-WROOM-02（ESP8266）

| ピン | 接続 |
|---|---|
| 3V3 | LDO 出力 |
| GND | GND |
| RST | Q1 コレクタ。10kΩ プルアップ + 1µF |
| EN (CH_PD) | 10kΩ で 3V3 へ |
| IO0 | Q2 コレクタ。10kΩ プルアップ |
| IO2 | 10kΩ プルアップ |
| IO15 | 10kΩ プルダウン |
| TXD | → CH9102F RxD |
| RXD | ← CH9102F TxD |
| IO16 | deep sleep を使う実機では RST と結線（治具では不要） |

- 2mm ピッチなので DIP 化基板（秋月 AE-ESP-WROOM-02 等）が必要。

### ESP32-WROOM-32E

| ピン | 接続 |
|---|---|
| 3V3 | LDO 出力 |
| GND | GND |
| EN | Q1 コレクタ。10kΩ プルアップ + 1µF |
| IO0 | Q2 コレクタ。10kΩ プルアップ |
| TXD0 (IO1) | → CH9102F RxD |
| RXD0 (IO3) | ← CH9102F TxD |

- IO0 以外のストラップピンは触らない。
  特に **IO12 (MTDI) を High に引かない**（フラッシュ電圧設定が 1.8V に変わる）。
- IO2 は内部プルダウンのまま開放で可。

## 6. 運用メモ

- 初回だけ治具でシリアル書き込みし、以後は OTA（ESPHome / ArduinoOTA）に切り替えると
  実機側で GPIO0 を触る必要がなくなる。
- ターミナルが DTR のみアサートする設定だと Q2 が ON になり IO0 が L になる。
  IO0 はリセット時にしかサンプリングされないので通常は無害だが、
  その状態で手動リセットすると書き込みモードに入る。
