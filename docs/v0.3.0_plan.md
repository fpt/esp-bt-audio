# v0.3.0 改版計画

v0.2.0（JLCPCB Economic PCBA）の実機確認と対照試験の結果から、v0.3.0 では i2s-power 基板のオーディオ部（PT8211 ＋ LM4881）を置き換える。
v0.2.0 の経緯・試験の詳細は `v0.2.0_conclusion.md` を参照。

## 1. v0.2.0 からわかったこと

| 項目 | 結果 |
|---|---|
| 起動・電源ラッチ・書き込み・Bluetooth・A2DP・LED | OK |
| Bluetooth 動作中の「ジー」というノイズ（約 100Hz ＋ 高調波） | **LM4881 の段から入る**（下の対照試験） |
| iPhone の音量を下げたときの歪み | PT8211 の小信号の直線性が原因と考えられる |
| ソフトウェア（音声データ、I2S の送り方） | 原因ではない（全サンプル 0 でもノイズは同じ） |

対照試験（2026-11-14、`v0.2.0_conclusion.md` 4 章）。ESP32・main 基板・i2s-power 基板の 3V3・I2S の配線は共通。

| 構成 | DAC | アンプ | ノイズ |
|---|---|---|---|
| T1 | PT8211 | LM4881 | あり |
| T2 | UDA1334A モジュール | なし（モジュールのジャックでイヤホンを直接駆動） | **なし**。とてもきれい（最大音量で少し歪む） |
| T3 | UDA1334A モジュール | LM4881 | あり |

- T2 がきれいなので、main 基板・ESP32・無線・3V3 レール・I2S は主な原因ではない
- T2 と T3 の差は LM4881 の経路だけ。LM4881 の電源（BYPASS ＝ VDD/2 経由で約 2 倍）か、LM4881・出力の 470µF・ジャックの GND から入る
- DAC だけを替えてもノイズは消えない。**DAC とヘッドホンアンプの両方を替える**
- T2 の最大音量での歪みは、ライン出力で低インピーダンスのイヤホンを直接駆動しているため。ヘッドホンアンプを入れれば解消する

## 2. v0.3.0 のオーディオ部

```
ESP32 ── I2S（BCK / WS / DIN）──► DAC（標準 I2S、MCLK なし）── ライン出力 ──► ヘッドホンアンプ（グラウンド基準）──► ジャック
                                                                               ▲ EN ＝ SHUTDOWN 線（GPIO23）
```

### 2.1 DAC

| 候補 | 内容 | 備考 |
|---|---|---|
| PCM5102A（PCM5101A、PCM5100A はピン互換） | 3.3V、オーバーサンプリング、内部 PLL で BCK から動作（MCLK・I2C 不要）、グラウンド基準のライン出力 | PCM5102APWR（C107671）は 2026-11-13 時点で LCSC の在庫 0。ピン互換品も含め在庫を確認する |
| UDA1334ATS | T2 で使ったもの。内部 PLL で WS から動作（MCLK・I2C 不要） | 実機で確認済み。在庫と供給状況を確認する |

- どちらもファームウェアは `CONFIG_BTR_DAC_I2S`（Philips I2S、16 ビットスロット、BCK = 32fs、L が先）で動く
- 形式やフィルタなどの設定ピンは、プルアップ／プルダウンで固定する（I2S 形式、ミュート解除、ディエンファシスなし）
- DAC のミュート（PCM5102A の XSMT など）をアンプの EN と同じ線で制御すると、起動・停止時の音が出にくい。データシートで確認する

### 2.2 ヘッドホンアンプ

- 出力がグラウンド基準（チャージポンプ内蔵）で、出力コンデンサと BYPASS（VDD/2）がないもの。候補: TPA6132A2、MAX97220 など
- 電源除去比（PSRR）が高いもの。データシートで 100Hz〜1kHz の値を確認する
- 3.3V 単電源で動き、シャットダウン時の消費電流が µA 以下
- EN は今の SHUTDOWN 線（GPIO23）を使う。LM4881 の SHUTDOWN は High でオフだったが、EN は High でオンになる。オフを既定にするため、プルアップをプルダウンに替え、ファームウェアの極性を変える
- ゲインは、iPhone の音量を最大付近で使っても大きすぎない値にする（小信号の歪みとノイズを避けるため）。可変ゲインのものなら低めに設定する

### 2.3 電源

- T2 では UDA1334A モジュールを i2s-power 基板の 3V3 から給電してきれいだった。DAC は 3V3 からフェライトビーズ（または小さな抵抗）＋ パスコンで給電する
- アンプも同様に 3V3 から、フェライトビーズ ＋ 10µF 以上 ＋ 0.1µF で給電する
- 試作でノイズが残る場合に備え、アナログ専用 LDO（VDD から、EN は 3V3_EN）のフットプリントを置き、ジャンパ（0Ω）で 3V3 と切り替えられるようにしておくかを検討する。LDO は電池 3.2V（自動電源オフ）でも動くドロップアウトのものを選ぶ
- 全負荷を RT9080 の出力（または 3V3_EN で止まる LDO）から取る方針は変えない。電源オフ時に µA 程度に保つ

### 2.4 GND と配置

- アナログ部（DAC のアナログ側、アンプ、ジャック）の GND をまとめ、RT9080（または電池 −）の近くで GND につなぐ
- ESP32 の電流ループ（RT9080 → ヘッダ 3V3 → ESP32 → ヘッダ GND → RT9080 の GND）がアナログ部の下を通らない配置にする
- ヘッダの NC ピン（8〜10）を GND に割り当て、GND のインピーダンスを下げる
- RT9080 の出力の C13（1µF）を 10µF に増やす
- チャージポンプのコンデンサは IC の直近に置く

### 2.5 その他

- main 基板と ESP32 の GPIO（BCK 26、WS 25、DATA 27、SHUTDOWN 23）は変えない。ヘッダの信号も同じ（MCLK のピンは使わない）
- DAC とアンプは PCBA で実装する（v0.2.0 の PT8211 の手はんだの失敗を繰り返さない）。部品番号は発注前に `lcsc-check` で確認する
- DAC とアンプが 1 つになった IC（TLV320DAC3100 など）は I2C が要り、main 基板とヘッダの変更が必要になるので選ばない

## 3. ファームウェア

| 項目 | 内容 | 状態 |
|---|---|---|
| DAC の形式 | `CONFIG_BTR_DAC_I2S` | 済（2026-11-14、UDA1334A で動作） |
| L/R の順 | 標準 I2S で L が先。テストトーン（`CONFIG_BTR_TEST_TONE`）で確認する | 未確認 |
| アンプ EN の極性 | High でオン（LM4881 の SHUTDOWN とは逆）。Kconfig で切り替える | 未対応 |
| 送信電力の制限（-6dBm） | v0.3.0 でノイズが消えたことを確認したら外す（通信距離のため） | 暫定で有効 |
| アンダーランのカウント | `10 s:` のログに出す。動作確認が済んだら残すか決める | 済 |

## 4. 発注前の確認

1. DAC とアンプの候補の在庫（JLCPCB / LCSC）、基本部品か拡張部品か
2. アンプの PSRR、ゲイン、EN の極性、シャットダウン電流をデータシートで確認
3. 可能なら、DAC モジュールとアンプのモジュール（評価ボード）を組み合わせ、T2 と同じ条件でノイズがないことを確かめる
4. 回路図 → ERC / DRC → `lcsc-check` → 発注
