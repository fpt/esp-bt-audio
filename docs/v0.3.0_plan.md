v0.2.0（JLCPCB Economic PCBA）の実機確認で見つかった問題と、v0.3.0 での対策をまとめる。
回路変更は v0.2.0 での手直し（検証 A〜C）で効果を確かめてから決める。

## 1. v0.2.0 の実機結果（2026-11-11）

| 項目 | 結果 |
|---|---|
| 起動・電源ラッチ・書き込み | OK |
| Bluetooth ペアリング、A2DP 再生（iPhone、SBC 44.1kHz） | OK |

### 1.1 PT8211 の実装

届いた基板では PT8211 が正しく実装されておらず、音が出なかった（ノイズのみ）。手で付け直して動作した。
v0.3.0 の発注前に、CPL の PT8211 の回転と、フットプリントの 1 番ピンの位置を確認する。

### 1.2 ノイズの状況

- Bluetooth を止める（テストトーン、無線 OFF）とノイズは消える
- 送信電力を -6dBm に下げても少し減るだけ（ファームウェアで暫定的に制限中）
- ESP32-Downloader 給電でも LiPo 給電でも変わらない
- 再生していなくても、接続中で iPhone の画面が点いている間は出る（無線の通信頻度に連動する）

## 2. 原因（推定）

i2s-power 基板の 3V3 が 1 本のレールになっている。

```
RT9080 ─┬─ C13 1µF
        ├─ ヘッダ ─► ESP32（無線動作時にパルス状に 100〜300mA）
        ├─ PT8211 VDD（C6 0.1µF ＋ C8 10µF）
        └─ LM4881 VDD（C7 0.1µF ＋ C9 10µF）
```

- **PT8211 は電源除去比がほぼない。** 抵抗ラダー型 DAC で、出力は VDD の分圧（無信号で VDD/2）。3V3 に乗ったリップルがそのまま音声出力に出る
- ESP32 の無線のパルス電流が、ヘッダと RT9080 の出力を通って 3V3 を揺らす。main 基板の C5（100µF）は ESP32 側の変動を抑えるが、i2s-power 基板側の 3V3 は守れない
- ESP32 の戻り電流が、ヘッダの GND を通って PT8211 / LM4881 / ジャックと同じ GND を流れる
- 給電元を変えても変わらないので、RT9080 のドロップアウトや電池の内部抵抗が主因ではない

## 3. v0.2.0 での検証（発注前）

効果の大きい順に試し、結果をこの表に記録する。

| # | 手直し | 方法 | 結果 |
|---|---|---|---|
| A | PT8211 電源の RC フィルタ | PT8211 の 5 番ピンを浮かせ（またはパターンを切り）、3V3 から 22〜33Ω を直列に入れ、5 番ピン直近に 100〜220µF ＋ 0.1µF を GND へ。fc ≈ 7〜70Hz | |
| B | GND の追加配線 | main 基板の ESP32 GND と、i2s-power 基板の RT9080 の GND を太い線で直結し、ESP32 の戻り電流をオーディオ部の GND に流さない | |
| C | LM4881 電源の強化 | LM4881 の VDD にフェライトビーズ（または 2.2〜4.7Ω）＋ 47〜100µF。BYPASS の C4 を 1µF → 2.2〜4.7µF（PSRR 改善。起動が遅くなり、ポップ音が変わるので確認する） | |

- PT8211 の消費電流は数 mA なので、33Ω でも電圧降下は 0.1V 程度。出力レベルがわずかに下がるだけ
- A で消えれば PT8211 の電源が主経路。B でさらに減れば GND の共通インピーダンスも効いている

## 4. v0.3.0 の変更案

検証結果で 4.1 の案を選ぶ。4.2 以降はどの案でも入れる。

### 4.1 アナログ電源の分離

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| 1 | PT8211 の VDD に RC フィルタ（22〜33Ω ＋ 100µF ＋ 0.1µF）。LM4881 はフェライトビーズ ＋ 47µF | 部品が少ない。検証 A そのまま | 3V3 の変動が大きいと低域が残る |
| 2 | アナログ専用 LDO（低ノイズ・高 PSRR、2.8〜3.0V）を VDD から取り、PT8211 と LM4881 に給電。EN は 3V3_EN | 無線の影響をほぼ受けない | 部品が増える。電池 3.2V（自動電源オフ）でも動くドロップアウトの LDO を選ぶ。PT8211 の入力 High 閾値（VDD 依存）を 3.3V ロジックで満たすか確認 |
| 3 | 案 2 に加え、ESP32 用の LDO を main 基板に置き、ヘッダでは VDD を渡す | ESP32 の大電流が i2s-power 基板の 3V3 と GND を通らない | ヘッダと両基板の電源まわりを作り直す。電源ラッチ（3V3_EN）を両 LDO に配る |

### 4.2 GND と配置

- アナログ部（PT8211 / LM4881 / ジャック / C4）の GND をまとめ、RT9080（または電池 −）の近くで 1 点で GND につなぐ
- ESP32 の電流ループ（LDO → ヘッダ 3V3 → ESP32 → ヘッダ GND → LDO GND）がアナログ部の下を通らない配置にする
- ヘッダの NC ピン（8〜10）を GND に割り当て、GND のインピーダンスを下げる
- RT9080 の出力の C13（1µF）を 10µF に増やす

### 4.3 その他

- PT8211 の CPL 回転・1 番ピンの確認（1.1）
- ヘッダのピンを変える場合も、ESP32 の GPIO 割り当ては変えない（ファームウェアを v0.2.0 と共通にする）
- 送信電力の制限（ファームウェア）は、v0.3.0 でノイズが消えたら外す（通信距離のため）
